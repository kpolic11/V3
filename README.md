# Lumina: Η Ιστορία & Τέχνη της Φωτογραφίας (v2)

Τρίγλωσση (ελληνικά / English / Español) εφαρμογή για νέους φωτογράφους.

## Τι υπάρχει
- **21 κεφάλαια** σε 6 μέρη + οδηγό. Κάθε κεφάλαιο έχει κατάσταση: `full` (πλήρες), `short` (σύντομο), `planned` (ετοιμάζεται).
  Το κεφάλαιο 1 «Ο Σκοτεινός Θάλαμος» είναι το πρώτο πλήρες δείγμα: ενότητες, «Κοίτα προσεκτικά», άσκηση, «Το ήξερες;», τεστ, πηγές.
- **Εργαστήριο Έκθεσης & Κάδρου**: 12 μαθήματα έκθεσης και 18 μαθήματα σύνθεσης, με σχέδια και διαδραστικά παραδείγματα
  (στοπ, ισοδύναμες εκθέσεις, ιστόγραμμα, φωτόμετρο, ισορροπία λευκού, λειτουργίες λήψης).
- Προσομοιωτής τριγώνου έκθεσης, παιδότοπος σύνθεσης, χρονολόγιο, πρωτοπόροι, συμβουλές, κουίζ.
- Αφήγηση Gemini TTS ανά ενότητα (με εφεδρική φωνή του browser), PDF κεφαλαίου.

## Πού βρίσκεται το περιεχόμενο
| Τι | Αρχείο |
|---|---|
| Κουμπιά & μηνύματα (3 γλώσσες) | `src/i18n/ui.ts` |
| Λίστα κεφαλαίων, εικόνες, κατάσταση | `src/data/chapters/base.ts` |
| Κείμενα κεφαλαίων | `src/data/chapters/{el,en,es}/` |
| Μαθήματα εργαστηρίου | `src/data/lab/{base,el,en,es}.ts` |
| Πρωτοπόροι | `src/data/pioneers.ts` |
| Συμβουλές, κουίζ, χρονολόγιο | `src/data/general.ts` |
| Ιστορικές εικόνες (Wikimedia Commons, public domain) | `src/data/media.ts` |

Για να γράψεις ένα κεφάλαιο ολόκληρο: πρόσθεσε ενότητες στο `src/data/chapters/el/…` (και στα en/es) και άλλαξε
το `status` σε `'full'` στο `base.ts`. Αν λείπει μετάφραση, η εφαρμογή δείχνει το ελληνικό κείμενο με σημείωση.

## Εκτέλεση
1. `npm install`
2. Βάλε `GEMINI_API_KEY` στο `.env` (δες `.env.example`)
3. `npm run dev`
